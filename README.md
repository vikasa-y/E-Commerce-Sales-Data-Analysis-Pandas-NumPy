# 🛒 E-Commerce Sales Data Analysis

A beginner-friendly data analysis project using **Python, Pandas, and NumPy** to explore an e-commerce dataset.

### 🔧 Tools Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

### 📊 Analysis

* Data inspection & cleaning
* Product category analysis
* Payment method analysis
* Regional analysis
* Revenue analysis
* Date/Time analysis
* Numerical analysis with NumPy

### 🎯 Goal

To practice working with a real-world dataset and extract meaningful insights using **Pandas and NumPy**.
